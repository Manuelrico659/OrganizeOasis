# Configuration

This document provides details about the configuration required to set up the application.

## Configuration Steps

1. **Environment Variables**:
   - `DATABASE_URL`: URL to the database (e.g., `postgresql://user:password@localhost/dbname`)
   - `SECRET_KEY`: Secret key for application security.

2. **Configuration Files**:
   - Ensure that configuration files (`config.yml`, `config.json`) are correctly set up for environment-specific configurations.
